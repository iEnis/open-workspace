# Open Workspace

Open folders directly with File Explorer and/or Windows Terminal

## Features

Adds 2 Butttons

- Reveal in File Explorer and Terminal: Opens the selected folder in your File Explorer of choise (works with other ones like File Pilot) and Windows Terminal
- Reveal in Terminal: Opens the selected folder in Windows Terminal

## Requirements

Requires Windows Terminal and only works on Windows
